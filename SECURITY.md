# Security Policy

## Supported Versions

Security updates are provided for the latest code on the `src` branch.

## Reporting a Vulnerability

Please do **not** report security vulnerabilities through public GitHub issues.

Instead, report them privately to ECMWF using one of these channels:

- Email: **software.support@ecmwf.int**
- If available to you, use ECMWF's official security or support contact process.

Please include:

- A description of the issue
- Steps to reproduce
- Potential impact
- Any suggested remediation

ECMWF will acknowledge receipt and review the report. Please avoid public disclosure until the issue has been assessed and, where appropriate, remediated.
